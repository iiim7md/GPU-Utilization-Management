
# GPU Utilization Management

COSC230 - Object-Oriented Programming
Fall 2026 - Khalifa University

## Project Description
A Java Swing desktop application that simulates
the management of four NVIDIA H100 GPUs.

## Features
- Student registration and login
- Administrator approval
- GPU time allowances
- Job submission and FCFS scheduling
- Simulated clock
- Job cancellation
- GPU utilization dashboard
- File-based persistence

## Project Structure
- model: Data classes
- logic: Application and business rules
- ui: Swing interface
- storage: File persistence

## Team
- Member A: Accounts and allowances
- Member B: Jobs and scheduling
- Member C: Application integration and persistence

## Requirements
- Java JDK 17 or newer
- Eclipse IDE or another Java IDE

## Running
Run ui.Main as a Java Application.
